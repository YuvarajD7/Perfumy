# Perfumy – Perfume Website

## About the Project
Perfumy is a simple perfume website developed using React. This project helped me understand how to build a website using reusable React components and organize a user interface into different sections.

## Technologies Used
- React.js
- HTML
- CSS
- JavaScript

## Features
- Simple and attractive user interface
- Product section to display perfumes
- Search bar UI
- Contact section
- Reusable React components

## What I Learned
- Creating and using React components
- Understanding JSX syntax
- Applying inline CSS styles in JSX
- Organizing a website into reusable sections
- Understanding how components work together in React
- Improving my frontend development skills

## Purpose
The main purpose of this project was to practice React fundamentals and gain practical experience in building a simple website using components.

## Conclusion
Building Perfumy was a valuable learning experience that helped me strengthen my understanding of React and frontend development. I also learned how to structure a website using components and apply styling to create a clean user interface.
